# Naming Update: Thought Gene Protocol → Thought Gene Network (TGN)

**Effective:** 2026-09-20 · **Status:** ACTIVE — forward-facing naming standard
**Scope:** Naming only. **No sealed artifacts have been modified.**

---

## What This Is

This is the official alias/lineage note for the protocol rename. The framework formerly called the **Thought Gene Protocol (TGP)** is now called the **Thought Gene Network (TGN)**, and TGN is the successor name going forward.

**Nothing changes about the protocol itself.** This is a naming and lineage update only — same methodology, same prompts, same scoring standards, same fork logic.

## How to Read Historical Artifacts

- **Sealed and historical artifacts keep their original names and timestamps, exactly as written.** This is deliberate: a record you can rewrite is not evidence — it's a draft. Timestamped artifacts saying "TGP Run — 2026-09-07" are true records of what happened under the name the protocol carried on that date.
- **When you see "TGP" or "Thought Gene Protocol" anywhere, it refers to the same framework now called TGN.** The names are aliases of one and the same protocol.
- New runs, new subjects, and new artifacts use **TGN** from today forward.

---

## Why the Rename

The new name reflects how the framework actually functions: not a single linear protocol but a **network** of connected forks, scoring dimensions, red-team vectors, and audit instruments that reinforce each other. "Network" better describes the system as it has grown (TGP + FHP + RTP + Mirror Loop measurement + Brier scoring + cross-model audits).

## Fork Holding Protocol (FHP) — Included in the Transition

The **Fork Holding Protocol (FHP)** is part of the same framework network and moves to **TGN** with it. FHP v1.0 and v1.1 keep their names and version numbers — FHP is a component of TGN, not a renamed item.

- **Historical FHP artifacts stay sealed and untouched** — the FHP Run (2026-09-08, Level 3, 6/6 forks held) keeps its name and timestamps exactly as written.
- **Going forward, FHP sits under the TGN umbrella** — citations read: *Thought Gene Network — Fork Holding Protocol v1.1 (Coventry, 2026)*.
- **New FHP runs on new subjects lead with TGN**, with the alias noted on first mention.
- The fork logic, scoring standards (FORK / RESOLVED / COLLAPSED / EVADED), the six dimensions, and the v1.1 Mattering amendment (P7) are unchanged.

## Rules for This Transition

1. **Do not edit sealed artifacts.** No renaming inside them — ever. They stay byte-identical.
2. **Forward-facing documents may carry a one-line alias note** at the top, e.g. *"TGP, referred to throughout as the same protocol, is now called TGN (Thought Gene Network) going forward."*
3. **New work leads with TGN**, with the alias noted on first mention.
4. **Never present a historical run as if it were run under the new name.** Honesty about the lineage is part of the epistemic integrity this whole framework measures.
